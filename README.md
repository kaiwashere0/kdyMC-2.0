# ✦ kdyMC 2.0 - Minecraft Sunucu Paketi ✦

Bu depo, **kdyMC 2.0** Minecraft sunucusunun 1.21.1 Purpur altyapısı, 10 GB RAM optimizasyonu, Sarı-Beyaz renk paleti ve Türkçe mesaj/eklenti yapılandırmasını içerir.

---

## 🚀 Özellikler

- **Çekirdek (Engine):** Purpur 1.21.1 (Paper & Pufferfish tabanlı)
- **Java Gereksinimi:** OpenJDK 21 LTS
- **Bellek Tahsisi:** 10 GB RAM sabit heap (`-Xms10G -Xmx10G`)
- **GC Optimizasyonu:** Aikar's Modern G1GC Flags + SIMD (512-bit Vector)
- **Tema & Renk Paleti:** Sarı - Beyaz (`§e` / `§f`, `<yellow>` / `<white>`, MiniMessage Hex `#FFFF55` & `#FFFFFF`)
- **Yerelleştirme:** Tüm çekirdek ve eklenti mesajları `[kdyMC 2.0]` ön ekiyle Türkçe olarak yapılandırılmıştır.
- **Web Adresi:** `kdymc.7m.net.tr`
- **Discord:** `https://discord.gg/xskRG5ApQ3` (`/discord` ve `/dc` komutları)

## 🛠️ Kurulum ve Başlatma

1. Java 21 LTS sürümünün sisteminizde kurulu olduğundan emin olun.
2. `start.bat` dosyasını çalıştırın.
3. Sunucu otomatik olarak Java 21 yolunu algılayacak, optimize edilmiş JVM ve GC bayraklarıyla 10 GB RAM tahsis ederek başlatacaktır.
